[#FFFFFF]Unicorns are creatures of light and purity. This one is neither. Its horn is just as sharp, though.[-]

[#f5e342]Origin[-]

The unicorn is one of the oldest legendary beasts, a wild horse with a single horn that only a pure maiden could tame. Dungeons & Dragons kept it as a fierce but good creature of the woodlands:

    "When a unicorn charges into combat it does not strike with its two front hooves, but its horn strikes for double damage... Once per day unicorns are able to use a teleportation spell of limited distance - a dimension door."
    - Monster Manual (1977), p. 98

Rogue's black unicorn is the dark twin of this creature, mean and hostile, with no Monster Manual entry of its own.

[#f5e342]Rogue Trivia[-]

The black unicorn is new in Rogue 5.4, where it took U from the umber hulk. Its numbers, though, came from the xorn of 5.2.1, the monster 5.4 dropped from X.

/* Rogue 3.6 - 1981 */
{ "xorn",	       0,	ISMEAN,	{ _x, 120, 7, -2, ___, "1d3/1d3/1d3/4d6" } },

/* Rogue 5.2.1 - 1982 */
{ "xorn",	       0,	ISMEAN,	{ XX, 190, 7, -2, ___, "1d3/1d3/1d3/4d6" } },

The only original version of rogue that features this monster is the 5.4 release.

/* Rogue 5.4 - 1983 */
{ "black unicorn", 0,	ISMEAN,	{ XX, 190, 7, -2, ___, "1x9/1x9/2x9" } },

/* EPYX DOS Version 1.48 - 1985 */
{ "ur-vile",       0,   ISMEAN, { XX, 190, 7, -2, ___, "1d3/1d3/1d3/4d6" } },

The Ur-vile in the EPYX DOS Version 1.48 has most of the same stats.

Advanced Rogue 5.8s also has an entry for a black unicorn in its monster list,
here it gets a regeneration ability.

{"black unicorn",
		35,	TRUE,	TRUE,	'u',	"4-6",
		{ISMEAN, ISREGEN},
		0, 0,
		5,
		{22,	900,	6,	1,	HPT("8d8"),
		"3d8"}},

Ultra Rogue 1.0.8 features a unicorn that has the blink ability.

Mike's Adventure Game also has an unicorn, this one gets a flavour string for its attack.
When you get hit, you are officially "hoofed".

/* Mike's Adventure Game */

	(NOGRAB | BLUE),

Like the Monster Manual's unicorn, the rx1 black unicorn charges with its horn, can blink a short distance away, and cannot be held by magic.
